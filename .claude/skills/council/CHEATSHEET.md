# 🧑‍⚖️ Council Cheat Sheet

**What it is:** a team of read-only AI reviewers that stress-test a plan or change before it reaches you. They advise; **your "go" is the only thing that ships anything.**

## Commands
| Say this | What happens |
|---|---|
| `/council` (or "run the council") | The 3 core reviewers + the right specialists review the current plan/change. |
| `/council with CPA` / "add a Finance Auditor" | Convene the core + that specialist for one task. |
| `@add-specialist <Name>` | Create a new reusable specialist (e.g. `@add-specialist Data-Scientist`). |

## When to run it
✅ Before committing to a real plan
✅ Before shipping anything touching **money, clients, tax, contracts, or your live system**
✅ When two approaches compete and you want the trade-offs surfaced

## When to skip it
❌ Typos, quick lookups, casual questions — it won't fire on these on purpose (saves cost)

## The team
**Core (always):** Senior Engineer · AI Architect · Project Director
**Specialists (auto-pulled by topic):** CPA-IRS · Finance-Auditor · Business-Analyst · Web-Auditor · Ecommerce-Bank-Auditor · Security · Legal-Reviewer · Performance-Optimizer · QA-Tester

## The rules that protect you
- Any one reviewer finding a real, pinpointed problem = **"fix first"** (no rubber-stamp voting).
- If the core three **disagree**, one extra specialist is pulled in to break the tie.
- If no specialist fits your topic, you're told plainly + given the command to add one.
- A full review costs real tokens (~380K), so it fires only for decisions that matter.

**Bottom line:** say `/council` for anything that matters, ignore it for small stuff, and nothing ever happens without your go.
